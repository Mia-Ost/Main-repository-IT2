# REA - reverse

## *oppgåve 1*

**1** **Kildekode og maskinkode**
Kjildekode er korleis koden er programert ofte i eir kodeprogram. Maskinkode er når koden er overført til binær eller 1 og 0

**2** **kompilering**
Kompilering betyr å overfære kildekode til binert med eit program.

**3** **Dekompilering**
Dekompolireing er det motsatte, dette kan verre vanskelig pga mykje informasjon blir tapt når bi kompilering. Mange folk dekompilerer gamle spill som måttes kompileres inn i game disks, sånn som pokemon pinnball.
[eg ville bare ha ein lenke i teksten](https://www.youtube.com/watch?v=qMn8j6u6uvA)

**4** **Reverse engineering**
Teste ut forskjellige egenskaper innenfor eit programm for å bygge ein forståelse for programet sånn [du](https://www.youtube.com/c/JoBj%C3%B8rnarHausnes/playlists?app=desktop) kan kopiere det.

**5** **modding**
Modding betyr at vi endrer [spill](https://www.youtube.com/watch?v=a56T2llZf_k), eller andre ting for å legge til egenskaper vi vil ha.

**6** **emulere**
å runne ein annen device på pcen din som nintendo 3ds, du treng fortsatt ein game key for å spille spillene på maskinen du emulerer.

**7** **open source og lisens**
open source betyr at alle har tilgang til koden til programme. Ein lisens er kva du har lov til å gjøre med open source programet.
